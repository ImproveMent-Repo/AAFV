# AAFV-04 — Unresolved Issues Report

Each item says why it is unresolved: missing evidence, unavailable resources, an experiment not yet run, or a methodological limit.

## Scientific blockers

| ID | Issue | Why unresolved | Resolution path |
|---|---|---|---|
| U-1 | No untouched confirmatory test set | MORPH test used twice; Look-2 design changed after Look 1 (re-trained checkpoint, new reject rule, new sets). Whether Look-1 results drove the changes is **unknown** from the repository | E1, plus a signed author statement on what was known when |
| U-2 | Certified FAR is at the ~3×10⁻³ scale | Only 1,170 / 1,149 person-disjoint impostor pairs exist per split | E5 (≥ 3,000 pairs per dataset for 1e-3) |
| U-3 | Reject-side control fails under shift | FG-NET adults: 18.20% genuine false rejects vs 1% target (46.70% all ages) | E3 (weighted conformal); direction N1 |
| U-4 | Cross-age benefit on MORPH not shown; ArcFace better in G1–G3 | Present data contradict it; long-gap MORPH pairs are scarce (224 test pairs in G4–G6) | E1 large-gap protocol; E2 matched-FAR comparison |
| U-5 | SAM identity preservation unmeasured; R_i circular | No independent recognizer scores or human study exist | E4 |
| U-6 | Value of the shared-target grid unestablished | It lowers acceptance; its neutral-rejection gain lies within CI overlap | E14 |
| U-7 | Hard-impostor result possibly an artefact of mined training negatives | Hypothesis from code plus Look-1 distributions; not tested | E8 |
| U-8 | Five Look-2 hard false accepts uncharacterized | Per-pair Look-2 outputs were not saved | E7 (forensic re-scoring, if the authors accept it under their protocol) |
| U-9 | Baselines incomplete | AdaFace, MagFace, AIFR, converged ViT, and selective classifiers not run; no per-pair baseline scores | E2, E6 |
| U-10 | Fairness limited to sex at Look 1, pair-level | Race labels not used; persons not logged in the Look-1 file | E9 |
| U-11 | Calibration under shift and Platt/isotonic/temperature comparison | Per-pair outputs exist only for Look 1 | E3 |
